# TorchCraft

A hands-on workspace for learning PyTorch and turning deep learning research into working code.

## Focus

- Practice PyTorch fundamentals, model building, and training workflows.
- Implement architectures and methods from research papers.
- Explore ideas through focused experiments and reproducible examples.

## Structure

- `Transformer/` — implementations and exercises related to Transformers.

This repository evolves alongside my learning, with an emphasis on clear code and understanding the ideas behind each implementation.
